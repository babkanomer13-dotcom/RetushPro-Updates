# RetushPro: переход со старого механизма обновлений

Этот канал содержит только небольшой самостоятельный переходник для установленных
RetushPro 1.9.5 и 1.9.5-win7-rc27. После запуска он использует ранее сохранённый
GitHub-токен, чтобы получить полное обновление из закрытого репозитория RetushPro.

В каждом ZIP два файла: `RetushPro.exe` (переходник) и `update.json` (описание
совместимости). В EXE есть код загрузчика и стандартные зависимости, но нет модулей
ретуши/редактора, весов моделей, фотографий или встроенных токенов. Обязательное
описание совместимости содержит названия, контрольные суммы и параметры конфигурации
модели — это условие проверки пакета уже установленной версией 1.9.5.

Архивы предназначены для встроенного механизма обновления. Это не самостоятельные
установщики RetushPro. Полные пакеты приложения доступны только в закрытом канале
с действующим токеном. После перехода обычная вкладка обновлений снова использует
сохранённый токен напрямую.
